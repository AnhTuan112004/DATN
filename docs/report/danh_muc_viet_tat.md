# DANH MỤC CÁC TỪ VIẾT TẮT

| Từ viết tắt | Từ đầy đủ | Mô tả |
| :--- | :--- | :--- |
| **HRM** | Human Resource Management | Quản trị nguồn nhân lực doanh nghiệp |
| **AI** | Artificial Intelligence | Trí tuệ nhân tạo |
| **ATS** | Applicant Tracking System | Hệ thống quản trị và sàng lọc hồ sơ ứng viên tuyển dụng |
| **API** | Application Programming Interface | Giao diện lập trình ứng dụng |
| **REST** | Representational State Transfer | Kiểu kiến trúc truyền trạng thái đại diện cho các dịch vụ web |
| **JWT** | JSON Web Token | Tiêu chuẩn mở truyền thông tin an toàn qua token JSON |
| **RBAC** | Role-Based Access Control | Mô hình kiểm soát truy cập phân quyền dựa trên vai trò |
| **IDOR** | Insecure Direct Object References | Lỗ hổng tham chiếu đối tượng trực tiếp không an toàn |
| **PII** | Personally Identifiable Information | Thông tin định danh cá nhân nhạy cảm |
| **EAR** | Eye Aspect Ratio | Tỷ lệ co mở mí mắt trong thị giác máy tính |
| **MAR** | Mouth Aspect Ratio | Tỷ lệ độ mở của miệng trong thị giác máy tính |
| **FPS** | Frames Per Second | Số lượng khung hình xử lý trên mỗi giây |
| **BLLĐ** | Bộ luật Lao động | Bộ luật Lao động nước Cộng hòa Xã hội Chủ nghĩa Việt Nam |
| **BHXH** | Bảo hiểm xã hội | Bảo hiểm xã hội bắt buộc theo quy định pháp luật |
| **BHYT** | Bảo hiểm y tế | Bảo hiểm y tế bắt buộc theo quy định pháp luật |
| **BHTN** | Bảo hiểm thất nghiệp | Bảo hiểm thất nghiệp theo quy định pháp luật |
| **TNCN** | Thu nhập cá nhân | Thuế thu nhập cá nhân theo luật định |
| **OT** | Overtime | Làm thêm giờ ngoài giờ làm việc tiêu chuẩn |
| **WFH** | Work From Home | Làm việc từ xa tại nhà |
| **ML** | Machine Learning | Học máy |
| **LLM** | Large Language Model | Mô hình ngôn ngữ lớn |
| **XAI** | Explainable Artificial Intelligence | Trí tuệ nhân tạo có khả năng giải thích nguyên nhân |
| **OOAD** | Object-Oriented Analysis and Design | Phương pháp luận phân tích và thiết kế hướng đối tượng |
| **UML** | Unified Modeling Language | Ngôn ngữ mô hình hóa thống nhất |
| **SUS** | System Usability Scale | Thang đo khả dụng chuẩn quốc tế đánh giá trải nghiệm người dùng |
