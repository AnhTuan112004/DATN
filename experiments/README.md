# THỰC NGHIỆM ĐỒ ÁN (EXPERIMENTS)

Thư mục lưu trữ toàn bộ dữ liệu đo lường thực nghiệm theo chuẩn khoa học:
- `faceid/trials.csv`: Nhật ký đo lường liveness, FPS, độ trễ và ROC FAR/FRR của FaceID.
- `payroll/cases.json`: 22 test cases đối chiếu bảng tính lương khớp 100% với Excel.
- `chatbot/test-130.json`: 130 câu prompt thử nghiệm (hợp lệ, vượt quyền RBAC, viết tắt, prompt injection).
- `uat/`: Bảng khảo sát SUS đánh giá trải nghiệm người dùng (mục tiêu SUS ≥ 75).
